## 📌 Project Overview

### 🔹 Level 1 &mdash; Web Fundamentals

1. **Task 1: Basic Webpage &amp; Form** (`level_1/Task_1/`)
   - Header with navigation links (`Home`, `Features`, `Contact`)
   - Styled hero section with heading, description, and relevant image
   - Contact form with client-side validation and feedback
   - Pure semantic HTML5 and CSS3 (no external frameworks)

2. **Task 2: JavaScript Basics** (`level_1/Task_2/`)
   - **Color-Changing Button**: Dynamically randomizes button background color on click
   - **Time-Based Greeting**: Displays a personalized greeting (Morning, Afternoon, Evening, Night) based on local system time
   - **Two-Number Addition Calculator**: Parses two numeric inputs and calculates the sum with validation

---

### 🔹 Level 2 &mdash; Intermediate UI &amp; Responsive Web

1. **Task 1: Front-End Frameworks** (`level_2/task_1/`)
   - **Bulma Component**: Responsive media card with author avatar, tags, publication time, and interactive footer buttons
   - **Bootstrap 5 Responsive Grid**: 12-column flexbox grid reorganizing across desktop (`col-lg-4`), tablet (`col-md-6`), and mobile (`col-12`) breakpoints

2. **Task 2: Responsive Web Design &amp; Hamburger Menu** (`level_2/task_2/`)
   - Adaptive multi-section layout: Hero, Stats, Services, Portfolio, Pricing, Contact, and Footer
   - **CSS Media Queries**: Smooth layout adjustments across desktop, tablet (`≤ 768px`), and mobile (`≤ 480px`) viewports
   - **Collapsible Hamburger Menu**: Animated 3-bar hamburger icon morphing into an `✕` that slides out a touch-friendly navigation drawer on mobile screens

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/adityarasal006-coder/internship_tasks.git
   cd internship_tasks
   ```
2. Open `index.html` in any web browser:
   - On Windows: Double-click `index.html` or run `start index.html` in PowerShell.
   - Or use VS Code Live Server extension.

## ⚙️ How to Enable GitHub Pages

1. Go to your repository on GitHub: `https://github.com/adityarasal006-coder/internship_tasks`
2. Click **Settings** &rarr; **Pages** (in the left sidebar).
3. Under **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**.
5. After 1–2 minutes, your live portfolio will be accessible at:
   `https://adityarasal006-coder.github.io/internship_tasks/`
