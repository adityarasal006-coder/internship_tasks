## 📌 Tasks

### 🔹 Task 1: Basic Webpage & Form
- Sticky navigation bar with smooth scrolling to sections (`#home`, `#about`, `#contact`).
- Hero section with heading, descriptive text, and a styled responsive image.
- 3-column CSS Grid showcasing feature cards with hover animations.
- Simple contact form with styled inputs and validation using pure HTML5 attributes.

### 🔹 Task 2: JavaScript Interactivity
- **Color Changer**: A button that cycles through colors dynamically on click.
- **Greeting Alert**: Detects local device time and triggers a time-aware greeting alert popup.
- **Calculator**: Adds two numeric inputs with validation and decimal handling.
