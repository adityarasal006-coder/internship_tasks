Part 2 • Bootstrap 5 Framework

Responsive Grid Layout

A standard 12-column flexbox grid adapting across mobile, tablet, desktop, and widescreen screens.

📱

Mobile-First (col-12)

On smaller handheld viewports (<768px), each card spans the full 12 columns for maximum reading comfort.

💻

Tablet Layout (col-md-6)

At the medium breakpoint (≥768px), columns gracefully reflow into a clean 2-column balanced grid.

🖥️

Desktop View (col-lg-4)

On large screens (≥992px), items evenly share width in an equidistant 3-column horizontal presentation.
